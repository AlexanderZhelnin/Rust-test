# PGO-сборка

Из корня проекта выполните:

```text
cargo xtask pgo
```

Команда автоматически:

1. Собирает инструментированный сервер.
2. Отправляет по одному smoke-запросу на дополнительные эндпоинты.
3. Обучает профиль на трёх основных эндпоинтах.
4. Объединяет данные LLVM.
5. Собирает финальный PGO-бинарник.

Результат на Windows:

```text
target/pgo/api_test-pgo.exe
```

Активный Rust toolchain должен быть установлен через `rustup`. Если компонент
`llvm-tools-preview` отсутствует, `xtask` установит его автоматически. Для
сборки `mimalloc` под Windows также нужны MSVC C++ Build Tools.

Параметры нагрузки можно переопределить:

```text
cargo xtask pgo --workers 100 --warmup-seconds 1 --training-seconds 5
```

Smoke-фаза покрывает `/`, `/readfile`, `/fibonacci` и `/naturalsortHack`. Основная тренировка выполняется для `/map`, `/mapJSON` и `/naturalsort`.

Нагрузки `/map` и `/mapJSON` циклически используют запрос без параметров и
значения `x/y`: `1`, `25`, `50`, `75`, `100`. Это соответствует диапазону из
существующего JMeter-сценария.
